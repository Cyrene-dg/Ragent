## Basic
- Material ID: 108343

## Description
荤素搭配的菜肴。将去皮切段的白萝卜先下锅煮，再放入处理好的大块鱼肉，加入调味料，小火焖煮而成。大块的食物带给人大大的满足感，用来搭配米饭再合适不过。

## Effect
队伍中所有角色暴击率提升9%，持续300秒。多人游戏时，仅对自己的角色生效。
