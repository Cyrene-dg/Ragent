## Description
用料丰厚的肉料理。原先是将烤肉排、土豆、奶酪堆叠而成的一道蒙德家常菜，后来作为羽球节的压轴菜声名远扬。

## Effect
队伍中所有角色暴击率提升15%，持续300秒。多人游戏时，仅对自己的角色生效。
