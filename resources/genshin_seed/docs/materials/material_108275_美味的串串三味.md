# Genshin Material: 美味的串串三味

## Basic
- Material ID: 108275
- CN Name: 美味的串串三味
- EN Name: Delicious Tri-Flavored Skewer
- Material Type: MATERIAL_FOOD

## Description
组合而成的串串。炉火纯青的温度控制，引动了滋滋作响的油花，多样的调料更是激发了食材的风味。少一分则淡，多一分则浓。而这一份不偏不倚的平衡之味，正是制作者所呈现出的匠心。

## Effect
队伍中所有角色攻击力提高228点，持续300秒。多人游戏时，仅对自己的角色生效。
