# Genshin Material: 渡来禽肉

## Basic
- Material ID: 108280
- CN Name: 渡来禽肉
- EN Name: Imported Poultry
- Material Type: MATERIAL_FOOD
- Item Type: ITEM_MATERIAL

## Description
淋满酱汁的肉料理。将禽肉腌渍后，挂上面糊炸熟，最后浇上浓厚的酱汁作为蘸料。搭配的蔬菜是当地物产，但腌渍方法和酱汁却是从外国传来，由此得名「渡来禽肉」。

## Effect
队伍中所有角色暴击率提升15%，持续300秒。多人游戏时，仅对自己的角色生效。
