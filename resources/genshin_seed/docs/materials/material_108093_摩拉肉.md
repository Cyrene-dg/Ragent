# Genshin Material: 摩拉肉

## Basic
- Material ID: 108093
- CN Name: 摩拉肉
- EN Name: Mora Meat

## Description
包裹大块肉馅的饼食。将烧饼一分为二，夹入浓郁肉馅。既解去了肉的腻味，又烘托了饼的香甜。为图富贵如意的口彩，通常还会印上「摩拉」的图案。

## Effect
复苏选中的角色，为其恢复100点生命值。
