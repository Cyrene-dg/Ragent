# Genshin Material: 稠汁蔬菜炖肉

## Basic

## Description
热乎乎的炖菜。将冷鲜肉和蔬菜切作小块，加上番茄久煮炖成浓稠的菜肴。汤汁包裹着被煮得暖洋洋的食材下肚，有着驱赶寒冷的效用。

## Effect
队伍中所有角色严寒积累速度小幅降低，持续900秒。多人游戏时，仅对自己的角色生效。
